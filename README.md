# سیستم مدیریت پمپ بنزین (Fuel Station Management)

وب‌اپلیکیشن مدیریت پمپ بنزین / تانک تیل برای پیگیری قیمت سوخت، فروش روزانه و موجودی مخازن (واردات و صادرات). تمام داده‌ها به‌صورت محلی در مرورگر (localStorage) ذخیره می‌شوند و نیازی به سرور یا پایگاه‌داده نیست.

## امکانات

- **داشبورد**: درآمد امروز، مجموع درآمد، مجموع واردات/صادرات، موجودی مخازن و نمودارهای درآمد ۱۴ روز اخیر، سهم درآمد و مقدار فروش به تفکیک سوخت.
- **قیمت‌ها**: تعیین قیمت هر واحد برای پترول، دیزل و گاز.
- **فروش**: ثبت فروش روزانه با نوع سوخت، مقدار، قیمت واحد و توضیحات؛ محاسبه خودکار مجموع.
- **موجودی**: ثبت واردات (ورود سوخت) و صادرات (خروج دستی)؛ موجودی باقی‌مانده = واردات − صادرات − فروش.
- رابط کاربری کاملاً فارسی و راست‌به‌چپ (RTL).

## اجرا

```bash
npm install
npm run dev      # اجرای محلی روی http://localhost:5173
```

## ساخت نسخه تولید

```bash
npm run build    # خروجی در پوشه dist
npm run preview  # پیش‌نمایش نسخه ساخته‌شده
```

## بررسی کیفیت کد

```bash
npm run lint       # oxlint
npm run typecheck  # بررسی نوع‌ها با TypeScript
```
